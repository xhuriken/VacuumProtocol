USAGE NOTES

- FBX is recommended for common real-time engine workflows.
- GLB is useful for pipelines supporting glTF 2.0.
- Keep each OBJ together with its matching MTL file.
- Include any required textures when packaging formats that do not
  embed them automatically.
- Shelf-box and empty-shelf modules are supplied in background and
  detailed variants.
- Aisle variants are supplied in red and white colour families.
- The main preview image shows an example warehouse shelving setup using
  props from the pack.
